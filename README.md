# tiny-chess-01

A chess engine in under 4 KB of Python, written from scratch for the
make.fun tiny-chess-01 bounty. 0x88 board, negamax with alpha-beta,
quiescence search, transposition table, killer moves, piece-square
evaluation. It plays the env protocol: `POST /game`, `POST /move`.
