A chess engine in under 4 KB of Python: a 0x88 board, negamax alpha-beta with quiescence search, a transposition table, killer-move ordering and MVV-LVA capture ordering, searching a fixed node budget per move so every trial replays identically.

## Run it

```sh
MAKEFUN_ENV_URL=http://localhost:8080 python3 main.py
```
